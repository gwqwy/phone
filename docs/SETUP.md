# 配置指引

三件事各自独立，按需配置。手机端只需要 shou 一个 App。

---

## 一、远控 ZCode 桌面端

1. 电脑上打开 ZCode → 「移动端远程控制」→ 出示二维码。
2. 手机上打开 shou → 点「扫码导入」（或「粘贴链接」）。
3. 回到 shou 首页，端点卡片上会显示连接状态。

**要点**：

- 链接长这样：`https://zcode.z.ai/remote/v4?sid=…&hash=…&t=…&name=…`。
  `sid` 与 `hash` 是凭据，`t` 是毫秒时间戳——shou 每次使用时都会重铸它，
  这就是界面里「刷新」的语义（旧链接会被桌面端判为过期）。
- **桌面端那个页面关掉，中继腿就离线了**，shou 会显示「等待桌面端」。
  这是正常状态，不是故障；把页面重新打开就会恢复。
- 同一时刻一个 `sid` 只允许一条连接：**官方远控页面开着会挤占它**，
  两边同时开会互相把对方踢掉（`KICKED`）。要么用官方页面，要么用 shou。
- 配对失效（显示「配对已失效，请重新扫码导入」）时，在端点卡片上长按 →
  「更换链接」，把新二维码的内容粘进去即可，设备记录、名字、顺序都保留。
- 自建中继也支持：端口与路径会被完整保留。

## 二、远控电脑端的 DeepSeek Harness

前提是电脑上已经装了 dsh。然后装 dsh-pocket 插件（**它是 GPL-2.0 的独立程序，shou 不包含它的代码**）：

```sh
npm install -g @deepseek-ai/dsh          # 若尚未安装；验证：dsh --version
dsh plugin --profile web add dsh-pocket -w
npx @deepseek-ai/dsh web
```

装好后在 dsh 的**设置 → 手机访问**里：

- **局域网**（同一 WiFi）：页面会给出二维码与地址，形如 `http://192.168.x.x:3081/`。
  局域网密码默认开启；想省事可以关掉（但那意味着同网段任何人都能操作你的电脑）。
- **公网**（人在外面）：点「开启公网访问」，走 Cloudflare 隧道。
  想要固定地址就用「命名隧道」并填自己的域名。

把地址或二维码内容导入 shou（带 `?token=` 的链接会把密码一起带过来，打开时自动填入）。

**要点**：

- shou 里的 dsh 端点**不会自己重写 cookie 或 token**：dsh-pocket 已经把信任栅栏的问题解决了，
  shou 只是把它的界面显示出来。所以第一次打开如果停在登录页，输一次密码即可，
  之后由 WebView 自己的 cookie 维持。
- dsh 首屏要 20–30 秒（node 启动 + 插件树）。shou 会在 8 秒后给出一个「重试」入口，
  不要以为它挂了。
- **公网地址等于把一台能执行代码的电脑暴露在互联网上**。shou 在导入公网地址时会弹一次提醒——
  请确认那个域名是你自己的隧道，而不是别人转发出来的。
- 明文 HTTP：局域网地址是 `http://`。若 HBuilderX 云打包后打不开局域网地址，
  在 `manifest.json` 的 Android 配置里确认允许明文流量（`usesCleartextTraffic`），
  或改用 https 的隧道地址。

## 三、在手机上跑 dsh（非 root）

shou 不含运行时，也装不了 Termux。这一步用 dsh-phone 的 **Shizuku 版**完成，
它是现成的"非 root 一键部署"：

1. 安装 dsh-phone 的 **Shizuku 版** APK（不要装 root 版）。
2. 打开它 → 点部署 → 按引导安装并激活 Shizuku
   （开发者选项 → 无线调试 → 配对码，**仅此一次**，不需要电脑）。
3. 粘贴 DeepSeek API Key → 点「一键部署」→ 完成后它会自动进入 dsh 界面。
4. 回到 shou → 添加端点 → 填 `http://127.0.0.1:3080`。

**要点**：

- 权限边界是 **adb shell 级**，系统天然受限：没有 `su`，因此没有 iptables、没有开机看门狗、
  也没有 DNS 自愈。这不影响 shou 使用它。
- 重启手机后需要打开一次 Shizuku 确认自启；dsh 由 Termux:Boot 拉起。
- 系统会冻结 Termux（尤其 MIUI）。如果 dsh 面板打不开，先去 dsh-phone 里重新进入一次界面。
- 想在手机浏览器或电脑上访问它，用 `adb forward tcp:3081 tcp:3080` 转发。

## 四、排错

| 现象 | 原因与处理 |
|---|---|
| ZCode 端点一直「等待桌面端」 | 桌面端「移动端远程控制」页面没开着；打开即可 |
| ZCode 端点「配对已失效」 | 链接过期或桌面端身份轮换；长按 → 更换链接，粘新二维码 |
| 一打开就被踢（KICKED） | 官方远控页面与 shou 同时在用同一个 sid，关掉其中一个 |
| dsh 面板白屏 | 首屏 20–30 秒；超过 8 秒点「重试」；仍不行则回 dsh-phone 重新进入一次 |
| dsh 面板停在登录页 | 地址没带 `?token=`；在 dsh-pocket 里重新扫码导入，或手动输一次密码 |
| 收不到通知 | Android 13+ 需要通知权限；另外把 shou 加进电池白名单（设置 → 后台） |
| 云打包后打不开 `http://` 地址 | 允许明文流量，或改用 https 隧道地址 |
